# FSM/UMI cover assets

The two PNG assets in this directory were extracted without alteration from the official Faculty of Sciences of Meknes cover template published at:

- Faculty page: https://www.fs-umi.ac.ma/index.php/theses/
- Official template: https://www.fs-umi.ac.ma/wp-content/uploads/2020/07/model-page-de-garde.docx

The public template is a doctoral-thesis template, not a Master PFE template. The report therefore reuses only its official dual UMI/FSM logo and blue-orange cover motif; the wording is adapted to the verified Master SDIA programme and the project's professional-English reporting requirement.

Downloaded and verified on 2026-08-01.
