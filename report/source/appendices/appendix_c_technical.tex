\section{Docker installation guide}

\subsection{Prerequisites}

Install Docker Desktop with Compose support and Git. Obtain the repository and create an environment file from the supplied example. Replace all sentinel values for database password, JWT secret, administrator password, and provider settings. Do not reuse demonstration secrets in a public environment.

\subsection{Startup}

\begin{lstlisting}[language=bash]
git clone https://github.com/BR1WA/energy-forecast-platform.git PFE2
cd PFE2
copy .env.example .env
# Edit .env and replace every insecure sentinel value.
docker compose up --build -d
docker compose ps
\end{lstlisting}

Verify:
\begin{lstlisting}[language=bash]
curl http://localhost:8000/api/v1/system/live
curl http://localhost:8000/api/v1/system/ready
curl http://localhost:3000/
\end{lstlisting}

The verified Azure deployment supplies managed TLS, Azure hostnames, private images, externalized secrets, a healthy email worker, ready SMTP capability, and a production Google identity origin. Web, API, and email worker use revision suffix \texttt{v4-d25295b}. The backend image caches the pinned foundation base, enables \texttt{FORECAST\_30D\_ENABLED}, and passed model warm-up at the API's two-vCPU and 4-GiB allocation. Public readiness reported the 24-hour, 168-hour, and 720-hour artifacts available, enabled, and warmed. The remediated source adds application security headers and a dedicated simulation worker; a new image promotion and cloud worker provision are required before those changes become Azure evidence. Remaining production work includes a custom domain, managed identity, durable avatar storage, centralized monitoring, simulation/alert/avatar workers, a shared rate-limit backend for horizontal scaling, and a tested backup-restore procedure.

\section{Report reproduction}

The report sources are modular. From \texttt{report/source}, run:
\begin{lstlisting}[language=bash]
python generate_figures.py
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
\end{lstlisting}
The final build process also runs Biber, renders the PDF with Poppler, checks log warnings, searches for unapproved placeholders and local paths, and packages the source tree.
